# 자율주차를 위한 객체 감지 및 영역 분할 통합 시스템 개발

**Autonomous Parking System: Integrating Object Detection & Semantic Segmentation**

AI Hub의 실내 자율주차 데이터를 활용하여, 복잡한 주차장 환경에서 **주차 가능 공간을 탐색**하고 **장애물 및 전용 주차 구역을 실시간으로 식별**하는 지능형 시스템입니다.

## 1. 프로젝트 개요

- **목표**: 실내 자율주행 시나리오에서 주행 가능 영역과 주차 공간을 구분하고, 장애물을 감지하여 안전한 주차 지원
- **데이터셋**: AI Hub 실내 자율주차용 데이터 (약 2.67 TB)
- **주요 성과**:
    - YOLOv8과 SegFormer를 결합한 하이브리드 추론 엔진 구축
    - 주차선 및 전용 구역 아이콘 인식을 통한 지능형 주차 상태 분류(Reserved, Blocked, Caution) 구현
    - 다중 객체 간 위상 관계 분석을 통한 후처리 알고리즘 개발

## 2. 시스템 아키텍처 (Key Technologies)

프로젝트의 효율성과 정확성을 위해 두 가지 특화된 모델을 병합한 파이프라인을 설계했습니다.

- **Object Detection (YOLOv8)**: 장애물, 차량, 보행자, 주차 표지판 등 13종의 객체를 실시간으로 탐지
- **Semantic Segmentation (SegFormer B0)**: 주행 가능 경로 및 주차 가능 영역을 픽셀 단위로 정밀하게 구분
- **Integrated Inference Engine**: 두 모델의 출력을 실시간으로 병합하여 최종 주차 상태를 판단하는 통합 프로그램 구현

## 3. 핵심 기술 및 문제 해결 (Technical Challenges)

### 3.1 하이브리드 판단 로직 및 후처리 (Main Contribution)

단순 탐지를 넘어 실질적인 주차 가능 여부를 판단하기 위해 다음과 같은 로직을 구현했습니다.

- **IoU 기반 상태 분류**: SegFormer가 찾은 '주차 영역'과 YOLO가 찾은 '객체(차량/장애물)' 간의 **IoU(Intersection over Union)** 및 중심점 포함 여부를 계산하여 실시간 상태 업데이트
    - **Reserved**: 영역 내 장애인/여성/경차 아이콘 탐지 시
    - **Blocked**: 영역 내 타 차량 혹은 라바콘 등의 장애물 존재 시
    - **Caution**: 영역 주변에 보행자가 감지될 경우 경고 표시
- **영역 분리 알고리즘**: 하나로 인식된 주차 공간 덩어리를 주차선 정보를 기반으로 **minAreaRect(최소 면적 사각형)** 및 좌표 클리핑 기법을 적용해 개별 주차 칸으로 정밀하게 분리

### 3.2 데이터 최적화 및 학습 전략

- **클래스 재정의**: 원본 29개 클래스를 실제 주차 시나리오에 맞춰 13개(YOLO)와 2개(SegFormer)로 전략적 병합
- **성능 개선**: 소수 클래스 인식률 저하 문제를 해결하기 위해 데이터 증강(Augmentation) 및 하이퍼파라미터 튜닝(Ray tune) 적용

## 4. 실시간 시각화 (HUD Implementation)

사용자가 시스템의 판단 근거를 한눈에 확인할 수 있도록 실시간 상태창(HUD)을 구현했습니다.

- 현재 프레임의 전체 주차 공간 요약 정보 표시
- 탐지된 객체 리스트 및 영역별 상태 코드 시각화
- 전용 구역(장애인 등)에 대한 직관적인 컬러 코딩 적용

## 5. 나의 기여 (My Role)

프로젝트 전 과정에 참여하며 특히 시스템의 **'두뇌'에 해당하는 통합 및 판단 로직**을 주도했습니다.

- **모델 구조 선정**: 프로젝트 목표에 최적화된 YOLO-SegFormer 병합 구조 제안
- **통합 인식 프로그램 개발**: 두 모델의 추론 결과를 병합하여 실시간으로 구동되는 메인 프로그램 작성
- **후처리 알고리즘 설계**: 주차 공간 개별 분리 및 객체 간 위상 분석 로직 전담 구현
- **시연 파이프라인 구축**: 최종 결과물 영상 생성 및 HUD 인터페이스 설계

## 6. 프로젝트 회고

- 자율주행 AI 개발의 전체 사이클(EDA -> 전처리 -> 모델링 -> 후처리)을 경험하며 실무적인 감각을 익혔습니다.
- 모델 성능의 한계를 수학적·알고리즘적 후처리 기법으로 보완하여 최종 서비스의 완성도를 높이는 엔지니어링 역량을 확보했습니다.
